# Java OOP Exercises

Object-oriented programming exercises in Java - practice with classes, inheritance, and encapsulation.

## Contents
| File | Concept |
|------|---------|
| `Person.java` | Basic class with fields and methods |
| `Animal.java` | Class modeling, behavior |
| `Vehicl.java` | Class modeling |
| `Book.java` | Class modeling |
| `Rectangle.java` | Geometry / methods |
| `BankAccount.java` | Encapsulation (state + operations) |
| `task5.java` | Exercise task |

## Running
Compile and run any file with the JDK:
```bash
javac Person.java
java Person
```
